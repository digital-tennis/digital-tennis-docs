# Digital Tennis 로고와 사용 안내

라켓·테니스 공·스윙 궤적·디지털 회로를 하나의 표식으로 결합했습니다. 작은 GitHub 프로필에서 읽히도록 글자 없이 구성했습니다. 짙은 네이비 배경과 라임·시안 표식입니다.

![Digital Tennis 로고](../assets/digital-tennis-github-avatar-500.png)

## 제공 파일

- [GitHub 업로드용 PNG](../assets/digital-tennis-github-avatar-500.png): 500×500px, 1MB 미만.
- [생성 원본](../assets/digital-tennis-logo-original.png).
- [최종 생성 프롬프트](../assets/logo-prompt.txt).

GitHub 공식 자료는 PNG/JPG/GIF, 1MB 미만과 3000×3000 미만을 요구하며 약 500×500을 권장합니다. [GitHub 프로필 이미지 규격](https://docs.github.com/en/account-and-profile/reference/profile-reference)

조직 소유자는 GitHub 조직 Settings의 프로필 이미지 편집에서 500×500 파일을 선택할 수 있습니다. 생성 파일을 제공하며 이 저장소 작업은 조직 프로필 이미지의 자동 변경을 포함하지 않습니다.

이미지는 기본 제공 imagegen 도구로 생성하고 업로드 파일은 크기를 조정했습니다. 원본을 별도로 유지합니다.
