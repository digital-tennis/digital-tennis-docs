# 처음 배우는 용어

| 용어 | 이 프로젝트에서의 뜻 |
| --- | --- |
| IMU | 가속도와 회전 속도를 측정하는 별도 센서 |
| 드라이버 | 센서 레지스터를 읽고 단위가 있는 값으로 바꾸는 코드 |
| 보정 | 정지 상태의 오차와 라켓 장착 방향을 반영하는 작업 |
| BLE | 보드와 PC가 사용하는 저전력 Bluetooth 통신 |
| GATT Service | BLE 기능을 묶는 식별 단위 |
| Characteristic | 읽기·쓰기·알림이 가능한 BLE 데이터 통로 |
| Notify | 보드가 PC에 새 값을 알리는 동작 |
| CCCD | PC가 알림 수신을 켜는 설정 |
| 코덱 | 구조체를 바이트로 바꾸고 바이트를 구조체로 읽는 코드 |
| little-endian | 여러 바이트 숫자의 작은 자리 바이트를 먼저 저장하는 방식 |
| CRC | 잘못된 바이트를 검출하는 검사값. 암호화나 인증 기능은 아님 |
| 시그널링 | 직접 통신을 준비하기 위한 연결 정보 교환 |
| P2P | 두 PC가 게임 메시지를 직접 주고받는 연결 |
| 릴레이 | 서버가 게임 메시지를 중간에서 전달하는 연결 |
| 호스트 권위 | 호스트 PC가 공·득점·승패의 최종 결과를 결정하는 방식 |
| 스냅샷 | 특정 tick에서 공·플레이어·점수를 묶은 상태 |
| 가상 입력 | 실제 컨트롤러 없이 키보드나 녹화 데이터로 만드는 동일 입력 |
| 수용 테스트 | 팀이 정한 완료 조건을 실제 동작으로 확인하는 검증 |
| 인일 | 개발자 1명이 하루 일하는 공수 |
