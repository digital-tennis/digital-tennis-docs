밸런스는 무실수 입력의 초기 실험을 그대로 선수 능력 평가로 사용하지 않았습니다. 입력 누락/대기/전진을 포함한 세 전략과17/4016/9001 시드·양쪽 선공을 고정하여 비교했습니다. `energy.hit_cost`4→3.2, `energy.move_cost`0.8→0.72 조정 후 종료 체력1 미만 비중은21.4%→14.7%, 평균 종료 체력은46.62→55.31입니다. 캐릭터의6개 능력치 합420은 유지합니다. 이 수치는 자동 입력 조건의 결과이며 사람 승률이 아닙니다.

아트와 연출은 기존 게임에서 추출하지 않은 원본 생성 메시/포즈/셰이더입니다. 국가 모티프는 창작 해석이며 신체/성별/실력을 국가 전체의 특성으로 일반화하지 않습니다. 영어 합성 음성은 최종 배우 녹음이나 각국 언어/억양 재현이 아닙니다.

작업 소스와 실제 증거의 기준은 [게임 초안 PR17](https://github.com/digital-tennis/digital-tennis-game/pull/17), [서버 초안 PR4](https://github.com/digital-tennis/digital-tennis-match-server/pull/4)입니다. 게임의 `docs/polish-backlog.md`, `docs/polish-validation.md`, `docs/reports/matchup-comparison.md`에서 코드별 상태와 재현을 확인합니다.

Mac 잠금을 유지한 게임 카메라 PNG와 게임 AudioListener WAV는 OS/다른 앱/마이크 캡처가 아닙니다. 같은Mac 두 프로세스는 서로 다른 두 PC/WAN 검증으로 바꾸지 않습니다. 실물Windows/두PC와 외장IMU/BLE, 직접P2P·공용WSS 운영은 실제 환경이 있어야 완료 처리합니다.

## 추가 오프닝/음향 요청

버블파이터와 테니스의 왕자 참고 영상을 실제 브라우저에서 확인하고 기존 코트·선수·공 자산으로12.5초/9컷 실시간 오프닝을 만들었습니다. 전경→집중→서브→공추적→리턴→스매시→라인→고유포즈→타이틀이며 컷 위치/주시점/FOV는 JSON으로 편집합니다. 건너뛰기/다시 보기/움직임 줄이기, 실제 점수/stock/physics tick 격리를 확인했습니다. [연출과 음향 상세](https://github.com/digital-tennis/digital-tennis-game/blob/main/docs/cinematic-and-court-audio.md).

경기 중 듀스/중요 포인트/스킬에도BGM은 정지하고 볼륨0입니다. 득점 때만 함성1회와 심판 콜을 재생하고 다음 서브 때 함성/환경음을 멈춥니다. 메뉴·오프닝·결과는 음악을 허용합니다. 곡 A/B의 사람 선택은 아직 미정이며 경기/듀스/긴장 곡은 설정 청음에서만 재생합니다.

Mac 잠금은 사용자가 수동 해제했습니다. 일반 창에서 실제 키보드 타격5접촉/듀스/다음서브와 새 빌드의 온라인로비 진입을 확인했습니다. 자동CUA마우스는 Unity포인터 좌표가 고정되는 문제로 실물마우스 통과로 계산하지 않습니다. 사용자 답변상 WindowsPC가 없어 실기/서로 다른 두PC·WAN은 미확인으로 남깁니다.

## 2026-10-18 현재 상태 보정

위 기록은 당시 소스의 이력이다. 이후 PR23에서 실제 DataChannel P2P/릴레이 복구가 구현·검증됐고, PR24에서는 일반 Mac 창의 실제 마우스20회·8개 키 입력 테스트·취소/저장 복귀를 확인했다. 현재는 해당 기능을 미구현/미검증 목록에 다시 넣지 않는다. Windows 실기·두PC/WAN·실제 외장 IMU 정확도와 공용WSS 운영은 별도다.
