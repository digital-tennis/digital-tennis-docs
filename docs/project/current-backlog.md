# DT-STS-00-00-00 · 현재 작업과 검증 기준

R01 / 2026-10-20. 최초12일·3명·36PD와 **NU40-DK + 별도 외장 IMU** 요구를 보존한다. 이 문서가 현재 작업 목록의 시작점이다. 날짜·커밋이 있는 과거 실행 수치와 초기 WBS는 이력으로 유지한다. ATA iSpec2200 공식 적합성을 주장하지 않는다.

## 10 완료한 제품 경계

- 단식 포인트→게임→세트→매치·타이브레이크·서브/엔드 교대, 자동 이동과 공통 타격 gate.
- Mac 일반 창 키보드·마우스 메뉴/경기, 저장/취소가 분리된 입력 설정, 끊김 시 정지.
- 15명 성인 페르소나/국기/세계지도, 캐릭터·코트·스킬·파티클·관중/심판/볼보이·개인 음성.
- 실제 DataChannel P2P 및 WebSocket 릴레이 전환·복구·재경기. 증거는 같은 Mac의 두 프로세스다.
- NU54 기존v2 실제 본딩·메시지 왕복·버튼 서브/양쪽 타격/스킬. 추가 버튼 반복 시험은 요구하지 않는다.
- v3 중립 물리6종/번호별Down·Up, 펌웨어/SDK/서버/게임의 역할 분리, 합성 센서·패킷·Unity 회귀.
- PPO 학습 샷 배치 모델의 게임 추론. 실제 AI 서브/리턴은 동작하며, 사람 서브 대기는 정지가 아니다.
- 자체 코드·문서 Apache-2.0. 외부 자산/도구는 원래 라이선스/고지를 보존한다.

규격의 정본은 protocol `spec/controller-v3.md`다. [물리 컨트롤러와 현재 main SHA](physical-controller-events.md)를 먼저 읽는다. 구형v1/v2 샷 API는 호환/비교 경로이며 새 펌웨어 기본 동작이 아니다.

## 40 AI 해석과 후속 확장

현재 PPO는 코스·깊이6액션을 선택하고 기존 실행 계층이 이동·서브·타격타이밍·스킬을 처리한다. 샷 배치 보상은 승률이 아니다. 실제 Unity의 짧은 고정 대진 포인트 점유율도 사람 승률이 아니다. 난이도 순서가 기대와 다르면 그대로 기록하고 추가 사람 평가 없이 자동으로 계수를 맞추지 않는다.

전체 경기의 score/done/reset을 포함한 학습 환경, 장기전술/자기대전·이동/서브/스킬 학습과 체크포인트 재개는 후속 확장으로 분리한다. [현재 학습 범위](learned-ai.md)와 AI 저장소의 `Training/README.md`가 기준이다.
